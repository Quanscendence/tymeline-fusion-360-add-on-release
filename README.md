# Tymeline Fusion 360 Add-in

Public download page for the Tymeline add-in for Autodesk Fusion 360 (Windows and macOS).

Each release attaches one install file, `TymelineFusion360-<version>.zip`. This repository does not contain the add-in source.

## Install

1. Open [Releases](https://github.com/Quanscendence/tymeline-fusion-360-add-on-release/releases) and download `TymelineFusion360-<version>.zip`, then unzip it.
2. In Fusion: **Utilities → Add-Ins** (Shift+S) → **Add-Ins** tab → green **+**.
3. Choose the unzipped `TymelineFusion360` folder.
4. Select **TymelineFusion360** in the list, tick **Run on Startup**, click **Run**.
5. Click **Pair** on the Design toolbar and paste the `TYM1.` key from the Fusion Desktop tile.

## Update

Stop the add-in in the Add-Ins dialog, replace the `TymelineFusion360` folder with the new one, click **Run** again.
